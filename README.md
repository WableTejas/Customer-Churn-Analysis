📊 Customer Churn Analysis Using Python & SQL

📌 Project Overview

Customer churn is a major challenge for businesses because losing customers can affect revenue and long-term growth.

This project focuses on analyzing customer churn using Python and SQL. The SQL database is connected to Python to retrieve and process data, perform data cleaning, conduct Exploratory Data Analysis (EDA), analyze customer behavior, and create visualizations.

The goal is to understand customer churn patterns and derive insights that can help businesses improve customer retention.

🎯 Project Objectives

Connect a SQL database with Python.

Extract and explore customer data using SQL queries.

Clean and preprocess the dataset.

Perform Exploratory Data Analysis (EDA).

Analyze customer churn patterns and trends.

Create visualizations to communicate insights.

Support data-driven customer retention decisions.

🚀 How to Run This Project

Prerequisites

Install Python and Jupyter Notebook on your computer.

Step 1: Clone the Repository

git clone https://github.com/WableTejas/Customer-Churn-Analysis.git

Step 2: Open the Project Folder

cd Customer-Churn-Analysis

Step 3: Install the Required Libraries

pip install pandas numpy matplotlib seaborn jupyter

Step 4: Launch Jupyter Notebook

jupyter notebook

Open churn_pro.ipynb and execute the notebook cells in order.

Note: Keep the SQLite database in the expected location used by the notebook. If the notebook uses a relative path, ensure the database filename and folder structure match that path.
